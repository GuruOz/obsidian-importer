## Append-only discipline (do not remove this section)
- Never rewrite, reorder, or delete existing content in any note.
- Only append new content, and only under the correct existing heading (or a new
  heading if none fits, per the heading conventions above).

## Idempotency marker (do not remove this section)
- Each night's digest insertion into the daily note is marked with an HTML comment:
  `<!-- copilot-digest:YYYY-MM-DD -->`
- Before inserting anything, check whether that day's marker already exists in the
  target daily note. If it does, the digest has already been filed - do not insert
  again, and say so in your summary.
